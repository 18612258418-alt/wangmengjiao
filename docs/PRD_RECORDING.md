# Memo 录音功能 PRD

## 1. 文档信息

| 项目 | 内容 |
|---|---|
| 功能名称 | 录音与实时转写 |
| 版本 | V1.0 |
| 适用产品 | Memo 学生版 |
| 核心入口 | 首页左侧栏搜索区域右侧的录音按钮；添加菜单中的「录音」 |
| 内容归属 | 录音原文件、实时转写稿及 AI 整理结果共同组成一条录音记忆 |

## 2. 需求目标

### 2.1 用户问题

- 课堂、讨论或口述记录过程中，手动记笔记会遗漏内容并打断注意力。
- 录音结束后需要重新听完整音频，查找重点成本高。
- 用户离开录音界面后，难以判断录音是否仍在继续。
- 录音、转写和笔记彼此割裂，后续无法直接检索和调用。

### 2.2 用户目标

- 一次点击即可开始记录课堂、讨论或个人口述。
- 录制过程中同步看到转写结果，及时判断是否正常收音。
- 收起录音窗口后可以继续使用 Memo，同时明确感知录音状态。
- 录音结束后可保存原音频与文字，并由 AI 形成可检索的笔记。

### 2.3 业务目标

- 提升课堂及口述类素材进入 Memo 的效率。
- 增加高信息密度学习素材的获取量。
- 将录音沉淀为可搜索、可挂靠知识点、可生成复习内容的长期记忆。
- 降低录音未开始、意外中断、录完未保存等失败率。

### 2.4 核心指标

- 录音入口点击率。
- 点击入口至成功开始录音的转化率。
- 麦克风授权成功率。
- 有效录音率：录音时长 ≥ 10 秒且成功保存。
- 实时转写成功率。
- 录音完成并保存到记忆的比例。
- 录音保存后 7 天内被搜索、打开或用于复习的比例。
- 录音异常中断率。

## 3. 功能范围

### 3.1 本期范围

- 录音入口。
- 麦克风权限申请。
- 开始、停止、关闭录音。
- 录音计时与动态波形。
- 边录音边转写。
- 展开态与顶部悬浮态切换。
- 录音完成后的转写确认。
- 保存录音和转写稿到 Memo。
- AI 对转写稿进行标题、摘要、知识点和后续行动整理。

### 3.2 暂不包含

- 多人声纹识别与说话人分离。
- 专业级录音剪辑、降噪和音轨编辑。
- 用户手动逐字校对转写时间轴。
- 实时翻译和双语字幕。
- 录音直播或多人共享。

## 4. 产品逻辑

### 4.1 内容对象

一条录音记忆包含：

| 字段 | 说明 |
|---|---|
| 录音文件 | 原始音频，作为可追溯来源保存 |
| 转写稿 | 带段落的识别文字；后续可扩展时间戳 |
| 标题 | AI 根据内容生成，用户可修改 |
| 摘要 | 录音核心内容概括 |
| 知识点 | 从转写中识别的概念、公式、结论或方法 |
| 来源信息 | 录制时间、时长、入口、关联学科和关联课程 |
| 后续行动 | 查看笔记、生成复习内容、生成作业或继续提问 |

录音原文件只保存一份。笔记、复习、作业等模块通过关联调用，不复制音频。

### 4.2 默认归类

1. 用户从某一学科页面发起录音：默认关联当前学科。
2. 用户从今日课程或课程详情发起录音：默认关联当前课程与时间。
3. 用户从首页发起录音：AI 根据转写内容识别学科；无法确认时进入「其他」。
4. 用户可在保存结果中修改学科和标题。
5. 录音本身作为来源保存；AI 提炼出的内容进入「笔记」。

### 4.3 状态机

```text
未开始
→ 请求麦克风权限
→ 录音中＋实时转写
→ 停止录音
→ 完成剩余转写
→ 展示转写结果
→ 保存中
→ 已保存到记忆
```

辅助状态：

```text
录音中 → 最小化 → 顶部悬浮录音态 → 重新展开
录音中 → 关闭 → 二次确认 → 放弃并退出 / 继续录音
```

### 4.4 实时转写规则

- 音频采集和语音识别同时启动。
- 转写区域固定高度，新增文字在框内自动滚动，不改变弹窗尺寸。
- 临时识别结果可持续修正；稳定结果按语义和停顿分段。
- 页面显示“实时转写”，避免用户误认为文字已经最终确认。
- 识别短暂中断时继续录音，并显示“转写暂时中断，录音仍在继续”。
- 停止录音后完成最后一段识别，再进入结果页。
- 无有效语音时不得生成虚假转写，提示“未识别到清晰内容”。

### 4.5 后台与最小化逻辑

- 点击最小化仅收起界面，不停止录音、计时和转写。
- 顶部悬浮态在 Memo 内跨页面保持显示。
- 悬浮态必须显示红色录制标识、当前时长和最近一段转写。
- 点击悬浮主体或展开按钮恢复录音弹窗。
- 悬浮态支持停止和关闭。
- 浏览器刷新、关闭标签页或退出应用前，若仍在录音，必须提示用户录音尚未结束。

### 4.6 关闭、停止与保存的区别

| 操作 | 结果 |
|---|---|
| 最小化 | 录音继续，界面变为顶部悬浮态 |
| 停止 | 结束采集，完成转写并进入结果确认 |
| 关闭 | 录音中需确认是否放弃；未录音或已保存时直接退出 |
| 保存到记忆 | 保存音频、转写稿和 AI 整理结果 |

关闭录音时不得直接丢失内容。确认文案：

> 当前录音尚未保存。关闭后将丢失本次录音和转写内容。

按钮：`继续录音`、`放弃并关闭`。

### 4.7 AI 整理逻辑

录音保存后，AI 异步完成：

1. 清理语气词、重复句和明显识别错误，但保留原始转写稿。
2. 生成标题与摘要。
3. 识别课程、学科、知识点、任务和时间信息。
4. 将明确的作业要求关联至作业模块。
5. 将需要巩固的知识关联至复习模块。
6. 生成“接下来可以做”，最多 3 项。

AI 判断不确定时只提出建议，不自动创建高风险任务或修改用户原内容。

## 5. 交互设计

### 5.1 入口

- 首页左侧栏：录音按钮位于搜索框右侧，与添加按钮并列。
- 图标采用“外圈＋实心圆点”的录制符号，不使用搜索语音的麦克风含义。
- Hover 提示：`开始录音`。
- 点击后打开居中的浅色弹窗浮层，不跳转页面。

### 5.2 未开始状态

弹窗包含：

- 顶部：关闭按钮、标题“点击开始录音”。
- 中部：静止波形。
- 主操作：圆形开始录音按钮。
- 辅助说明：录音将同步转写，保存后进入 Memo。

点击开始后：

1. 首次使用请求麦克风权限。
2. 授权成功后进入录音中状态。
3. 授权失败时显示原因、系统开启方法和“重新授权”。

### 5.3 录音中状态

弹窗包含：

- 顶部左侧：关闭、最小化。
- 顶部中间：状态“录音中”。
- 中部：动态波形、红色状态点、录音时长。
- 固定高度实时转写框。
- 主操作：停止录音。
- 说明：最小化后录音与转写仍会继续。

### 5.4 顶部悬浮态

悬浮条固定在页面顶部居中，不遮挡核心导航。

内容包括：

- 红色动态录制点。
- “正在录音”和累计时长。
- 最近一段转写，单行省略。
- 展开按钮。
- 停止按钮。
- 关闭按钮。

交互规则：

- 点击主体或展开按钮：恢复录音弹窗。
- 点击停止：结束录音并自动展开结果页。
- 点击关闭：出现放弃确认，不直接删除。

### 5.5 转写完成状态

- 停止后显示短暂的“正在完成转写”。
- 展示完整转写稿，转写区域固定高度并支持内部滚动。
- 主按钮：`保存到记忆`。
- 次按钮：`重新录音`、`删除`。
- 保存成功后显示去向：学科、笔记标题、录音时长。
- 用户可点击“查看笔记”或关闭弹窗回到原页面。

### 5.6 异常处理

| 异常 | 产品表现 |
|---|---|
| 麦克风权限拒绝 | 说明开启路径，提供重新授权和关闭 |
| 无麦克风设备 | 提示检查设备，保留上传音频入口 |
| 录音中断 | 保留已录内容，提示用户保存现有部分或重试 |
| 实时转写失败 | 明确说明录音仍在继续；停止后再次尝试完整转写 |
| 网络中断 | 本地继续录音；网络恢复后补传和转写 |
| 保存失败 | 保留本地草稿，支持重新保存，不让用户重新录音 |
| 音频过长 | 临近上限时提前提醒；达到上限后自动停止并进入保存 |

## 6. 埋点需求

### 6.1 公共字段

所有录音事件携带：

| 字段 | 类型 | 说明 |
|---|---|---|
| `user_id` | string | 用户标识 |
| `session_id` | string | 本次访问会话 |
| `recording_id` | string | 本次录音唯一标识，点击入口时生成 |
| `entry_source` | enum | `sidebar` / `add_menu` / `course` / `today_task` |
| `subject_id` | string/null | 当前关联学科 |
| `course_id` | string/null | 当前关联课程 |
| `client_type` | string | 设备与客户端类型 |
| `network_type` | string | 当前网络状态 |
| `timestamp` | datetime | 事件发生时间 |

### 6.2 事件表

| 事件名 | 触发时机 | 关键属性 |
|---|---|---|
| `record_entry_exposed` | 录音入口曝光 | `entry_source` |
| `record_entry_clicked` | 点击录音入口 | `entry_source` |
| `record_permission_requested` | 发起麦克风授权 | `permission_status_before` |
| `record_permission_result` | 返回授权结果 | `result: granted/denied/error`、`error_code` |
| `record_started` | 音频采集成功开始 | `start_latency_ms` |
| `record_live_transcript_started` | 首次出现实时文字 | `transcript_latency_ms`、`engine` |
| `record_minimized` | 点击最小化 | `duration_sec`、`transcript_char_count` |
| `record_expanded` | 从悬浮态重新展开 | `duration_sec`、`minimized_duration_sec` |
| `record_stop_clicked` | 点击停止 | `ui_state: modal/floating`、`duration_sec` |
| `record_close_clicked` | 点击关闭 | `phase`、`duration_sec` |
| `record_discard_confirmed` | 确认放弃 | `duration_sec`、`transcript_char_count` |
| `record_discard_cancelled` | 取消放弃并继续 | `duration_sec` |
| `record_transcription_completed` | 完整转写完成 | `duration_sec`、`char_count`、`success`、`error_code` |
| `record_save_clicked` | 点击保存到记忆 | `duration_sec`、`char_count`、`subject_id` |
| `record_save_result` | 保存完成或失败 | `success`、`error_code`、`save_latency_ms` |
| `record_ai_organized` | AI 整理完成 | `knowledge_count`、`task_count`、`review_count`、`latency_ms` |
| `record_result_action_clicked` | 点击结果页后续动作 | `action_type`、`target_id` |

### 6.3 漏斗

主漏斗：

```text
入口曝光
→ 点击录音
→ 权限成功
→ 开始录音
→ 停止录音
→ 转写完成
→ 保存成功
→ 后续内容被打开或调用
```

辅助分析：

- 按入口比较开始录音和保存转化率。
- 按录音时长分析保存率和后续调用率。
- 分析最小化用户的录音完成率是否高于未最小化用户。
- 统计权限拒绝、转写失败和保存失败的主要错误码。
- 统计录音形成笔记、作业、复习内容的比例。

### 6.4 指标口径

| 指标 | 计算方式 |
|---|---|
| 录音启动成功率 | `record_started` UV / `record_entry_clicked` UV |
| 授权成功率 | granted 的 `record_permission_result` / `record_permission_requested` |
| 实时转写成功率 | `record_live_transcript_started` 次数 / `record_started` 次数 |
| 录音完成率 | `record_stop_clicked` 次数 / `record_started` 次数 |
| 保存成功率 | success 的 `record_save_result` / `record_save_clicked` |
| 有效录音率 | 时长 ≥ 10 秒且保存成功的录音数 / `record_started` 次数 |
| 录音调用率 | 保存后 7 天内被打开、搜索或用于学习行动的录音数 / 保存成功录音数 |

## 7. 验收标准

- 点击录音入口后无需跳页即可打开录音弹窗。
- 首次录音会触发真实麦克风授权。
- 录音时波形、计时与实时转写同时更新。
- 转写框高度固定，内容增加不改变弹窗高度。
- 最小化后录音、计时和转写不中断。
- 悬浮态可展开、停止和关闭，三个操作结果明确不同。
- 关闭未保存录音前必须二次确认。
- 停止录音后展示完整转写稿。
- 保存失败时录音和文字不丢失。
- 保存成功后可在对应学科的笔记中找到录音记忆，并能追溯原音频。
- 所有核心事件按本文埋点定义正常上报，`recording_id` 可串联完整漏斗。
