# 课表切换与课程内容挂靠规则

## 1. 目标

学期课表不是一张只用于展示的图片，而是课程、学习资料和学习行为的时间索引。

用户切换学期时，系统必须同步切换：

1. 当前学期课表；
2. 左侧“我的课程”；
3. 每门课程挂靠的预习、课堂笔记、课后补充和备考内容；
4. 原课程表文件及其预览；
5. 当前周次、日期和课程状态。

禁止只替换学期名称而继续展示上一学期的数据。

## 2. 学期识别

上传 Excel、PDF、图片或其他课表文件时，按以下证据识别学期：

1. 文件正文中的学年、学期；
2. Excel 工作表名称；
3. 文件名；
4. 课程周次和开课日期；
5. 上传时间仅作为最后的弱推断依据。

统一保存为：

```ts
type SemesterTimetable = {
  semesterId: string;       // 例如 2026-2027-1
  semesterName: string;     // 例如 2026–2027 学年第一学期
  detectionEvidence: string[];
  sourceFile: {
    name: string;
    type: string;
    previewUrl?: string;
  };
  courses: TimetableCourse[];
};
```

无法确定时不得静默覆盖已有学期，应标记为“待确认学期”并让用户选择。

## 3. 多学期保存原则

- 不同学期的课表分别保存，可以长期并存。
- 上传同一学期的新课表时，只更新该学期，不影响其他学期。
- 同一学期多次上传时，以课程名称、教师、上课时间、地点、周次共同去重。
- 新文件包含已有文件没有的课程时，应合并补充，不得直接丢失。
- 每个学期保留自己的源文件，点击“查看原课程表”时预览当前学期对应的文件。

## 4. 切换行为

用户在“学期课表”中选择学期后，执行一次完整的状态切换：

```text
选择学期
→ 设置当前 semesterId
→ 读取该学期课表
→ 重建该学期“我的课程”
→ 读取这些课程挂靠的学习内容
→ 校正当前选中课程
→ 重置到该学期第 1 周或已保存的浏览位置
→ 展示该学期源课表
```

如果当前选中的课程不属于新学期，自动选中新学期第一门课程；不得继续显示旧学期课程详情。

## 5. 课程身份与挂靠

课程不能只按展示名称关联。每门课程需要稳定身份：

```ts
type CourseIdentity = {
  courseId: string;
  normalizedName: string;
  teacher?: string;
  classCode?: string;
  semesterId: string;
};
```

挂靠优先级：

1. 明确选择的课程和学期；
2. 课表中的课程 ID；
3. 课程规范名 + 教师 + 学期；
4. 文件正文、标题、上下文推断；
5. 仍无法判断时进入“待归类”，不得随意挂到同名课程。

同一门课程跨学期出现时，课程名称可以相同，但课程实例必须用 `semesterId` 隔离。上一学期的笔记不能默认出现在下一学期。

## 6. 学习内容模型

每条内容至少保存以下挂靠信息：

```ts
type LearningAttachment = {
  contentId: string;
  semesterId: string;
  courseId: string;
  contentType: "preview" | "class-note" | "review-note" | "homework" | "exam";
  sourceId: string;
  sourcePage?: number;
  sourceRange?: string;
};
```

界面中的对应关系：

- “开始预习”：当前课程、当前或下一次课的预习资料；
- “打开课堂笔记”：当前正在上课的课程笔记；
- “继续笔记”：该课程最近一条未完成的课后笔记；
- “备考”：当前学期该课程的知识、错题、作业和参考资料汇总。

## 7. 内容保留与去重

- 新上传内容默认新增，不得覆盖上一篇笔记。
- 只有文件指纹、页码/区域和正文指纹均相同，才视为重复。
- 同一 PDF 的不同页面分别挂靠，同时保留书籍的章节层级。
- 同一知识点可以挂靠多篇笔记和多份参考资料。
- 跨学期内容不自动合并；用户主动复用时保留来源学期。

## 8. 展示规则

切换后，所有可见模块必须读取当前 `semesterId`：

- 学期名称；
- 日课表与周课表；
- 左侧课程列表和知识数量；
- 教师、地点、周次；
- 预习、课堂笔记、继续笔记按钮；
- 知识与备考内容；
- “查看原课程表”。

空状态应明确说明“本学期暂无课程/内容”，禁止回退展示其他学期的数据冒充当前学期内容。

## 9. 侧边栏“我的课程”动态展示规则

“我的课程”不是完整课表的课程目录，而是当前学期已有学习内容的课程入口。

侧边栏过滤只作用于“我的课程”，绝不能反向删除、过滤或修改学期课表数据。日课表、周课表和原课表预览必须完整展示上传文件中成功识别的所有课程，包括暂时没有笔记或资料的课程。

### 展示条件

课程同时满足以下条件时才在侧边栏显示：

1. 属于当前选择的 `semesterId`；
2. 已经挂靠至少一条有效学习内容。

有效学习内容包括：

- 用户上传并成功解析的课件、PDF、图片、网页、音频或视频；
- 用户的圈画、截图、课堂笔记和课后补充笔记；
- 已保存的预习内容；
- 作业、练习、错题或备考内容；
- 用户主动保留的课程参考资料。

以下情况不算“已有内容”：

- 仅存在于学期课表中；
- 上传或解析失败；
- 正在处理中且尚未生成可查看结果；
- 已删除或已取消挂靠；
- 只有系统演示占位数据；
- 只有课程名称、教师、地点、时间等课表信息。

### 动态更新

- 新内容成功挂靠后，对应课程立即出现在侧边栏。
- 课程最后一条有效内容被删除或解除挂靠后，对应课程立即从侧边栏隐藏。
- 上传处理中的课程不提前出现；处理成功后再出现。
- 切换学期时只计算新学期内有内容的课程。
- 同名课程跨学期分别计算，不得借用其他学期的内容使课程显示。
- 内容被重新挂靠到另一门课程后，原课程与目标课程的显示状态都要重新计算。
- 侧边栏隐藏空课程时，课程仍完整保留在学期课表中。

### 展示内容

侧边栏课程项只显示：

- 区分课程的颜色点；
- 课程名称；
- 当前学期挂靠的有效内容数量，数量为 `0` 时不显示。

不显示教师、教室、周次、最近更新等课表元数据。

### 空状态

当前学期没有任何课程产生有效内容时，显示：

> 本学期还没有学习内容

并提供上传资料入口。禁止为了填满侧边栏而展示空课程或其他学期课程。

## 10. 验收标准

使用两份不同学期、课程不同的课表验证：

1. 两个学期都出现在学期选择器中；
2. 切换后日/周课表内容立即变化；
3. 左侧“我的课程”立即变化；
4. 当前课程不属于新学期时自动切换；
5. 课程资料只显示当前学期挂靠内容；
6. “查看原课程表”打开当前学期上传的源文件；
7. 刷新页面后仍停留在最后选择的学期；
8. 再上传其中一个学期的补充课表，不影响另一个学期。
9. 只有课表信息、没有学习内容的课程不出现在侧边栏；
10. 给课程上传并成功挂靠内容后，该课程立即出现；
11. 删除课程最后一条有效内容后，该课程立即隐藏；
12. 学期切换后，侧边栏只展示新学期有内容的课程。
