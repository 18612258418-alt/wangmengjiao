# Memo 新版本上线

本次更新带来「复习」和「提笔即写」两项新功能，让已有内容更容易回顾，也让新的知识与灵感更容易保存。

## 复习｜把学过的内容重新串起来

课程中的「复习」模块会根据已有学习内容提取知识点，并整理成更适合回顾的复习内容。

你可以：

- 按知识点查看复习内容；
- 快速回顾核心概念和重点；
- 在不同知识点之间切换，了解整体学习脉络。

进入任意学科，点击「复习」，选择一个知识点即可开始查看。

> 本期为复习内容展示版本，暂不支持在线作答、AI 批改和错题记录。

## 提笔即写｜圈下内容，自动成为记忆

本版本会在「设置」中默认开启「笔写模式」。连接手写笔后，可以直接在屏幕任意位置圈选感兴趣的内容。

圈选后，你可以：

- 快速查看 AI 解释，理解重点内容；
- 将圈选内容自动保存至 Memo；
- 随时回顾，持续积累自己的知识与灵感。

无需复制粘贴，也不用切换应用。看到想了解或想记录的内容，提笔一圈即可。
