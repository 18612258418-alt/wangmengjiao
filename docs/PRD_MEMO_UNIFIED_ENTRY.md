# Memo 统一智能入口 PRD

## 1. 文档信息

| 项目 | 内容 |
|---|---|
| 功能名称 | Memo 统一智能入口 |
| 版本 | V1.0 |
| 入口位置 | 首页左侧栏顶部，Memo 标识下方 |
| 入口组成 | 添加资料、文字提问、语音提问 |
| 目标用户 | Memo 学生版用户 |
| 产品状态 | 高保真原型，进入研发定义阶段 |

## 2. 功能定义

统一智能入口是用户与 Memo 交互的第一入口，将以下三种行为放在同一个输入区域：

1. **提供内容**：点击「+」添加文件、图片、扫描件等学习资料。
2. **寻找内容或获得帮助**：点击中间文字进入 AI 搜索与对话页面。
3. **直接表达需求**：点击麦克风进入 AI 搜索页面并立即开始语音输入。

入口不是传统搜索框。它同时承担「输入资料」「检索记忆」「提问」「继续行动」四类任务。

## 3. 产品目标

### 3.1 用户目标

- 不需要先判断应该去笔记、作业、复习还是资料。
- 可以用自然语言描述自己想找什么或想做什么。
- 可以用文字、语音或资料完成同一条交互链路。
- 搜索结果不仅返回内容，还能直接进入下一步学习行动。

### 3.2 业务目标

- 提升首页 AI 入口的发现率和使用率。
- 降低添加资料、搜索和语音入口分散造成的理解成本。
- 增加个人记忆的调用次数。
- 将检索结果转化为复习、作业、预习等实际行动。
- 为后续个性化 RAG 积累明确的用户意图与反馈数据。

### 3.3 核心指标

- 统一入口点击率。
- 首次进入后成功完成一次提问或添加资料的比例。
- 搜索成功率。
- 语音授权成功率与语音提交率。
- 搜索结果到下一步行动的转化率。
- 搜索后继续追问率。
- 无结果后联网补充的使用率。

## 4. 界面结构

```text
┌──────────────────────────────────────┐
│  +   明天需要预习什么？          🎙  │
└──────────────────────────────────────┘
   │             │                  │
   │             │                  └─ 语音提问
   │             └─ AI 搜索与对话
   └─ 添加资料
```

### 4.1 左侧「+」

- 独立点击区域。
- 点击后打开添加资料浮层。
- 不触发搜索，不进入对话页。
- 浮层覆盖当前界面约 60%，居中显示。

### 4.2 中间动态文字

- 展示用户可以直接提出的问题示例。
- 每 3 秒切换一次。
- 使用淡出、替换、淡入动画，不横向滚动。
- 点击任意文字区域进入搜索页面。
- 示例文案只负责启发，不自动提交该问题。

V1 示例：

- 找我做错过的积分题
- 明天需要预习什么？
- 整理最近的课程笔记
- 我最近总在哪里出错？

### 4.3 右侧麦克风

- 独立点击区域。
- 点击后打开搜索页面，并立即发起麦克风权限与录音状态。
- 不要求用户进入页面后再次点击麦克风。

## 5. 业务逻辑

## 5.1 意图分类

用户输入后，系统先识别意图，再决定检索和结果形态。

| 一级意图 | 典型表达 | 系统处理 |
|---|---|---|
| 查找内容 | “找我做错过的积分题” | 检索个人记忆，返回匹配内容和来源 |
| 回答问题 | “换元积分为什么要改上下限？” | 检索证据后生成回答 |
| 总结归纳 | “总结最近的物理笔记” | 聚合同一学科、时间和知识点的内容 |
| 学习判断 | “我最近总在哪里出错？” | 调用作答、错题、笔记和复习记录形成判断 |
| 计划行动 | “明天需要预习什么？” | 结合课表、任务、课程难度和已有资料生成建议 |
| 内容处理 | “把这份课件整理成复习内容” | 对用户指定或刚添加的资料执行解析与生成 |
| 继续操作 | “重做相关错题” | 进入对应的作答、复习或资料页面 |

## 5.2 检索优先级

检索顺序如下：

1. 当前页面或当前选中内容。
2. 用户个人记忆：笔记、作业、错题、复习记录、资料、课表。
3. 当前学科上下文。
4. 用户画像：目标、近期学习状态、常见错误和偏好。
5. 公开网络资源，仅在个人记忆不足且问题需要外部信息时调用。

不得把全部历史聊天直接拼入提示词。用户画像、历史行为和长期记忆应参与检索与重排。

## 5.3 结果生成原则

每次回答至少包含：

- **直接结果**：先回答用户当前问题。
- **下一步可以做**：只显示与本次意图直接相关的操作。
- **记忆依据**：默认收起，用户主动展开查看。

结果页采用对话形式，不使用左右双栏信息面板。

### 回答要求

- 用户语言优先，不暴露“检索、重排、置信度”等后台术语。
- 先给结论，再给解释。
- AI 判断必须可以追溯到笔记、作业、资料或公开来源。
- 没有证据时明确说明“目前没有足够记录”，不得伪造个人结论。

## 5.4 下一步行动生成

根据意图动态返回最多 3 个动作：

| 场景 | 可返回动作 |
|---|---|
| 找到错题 | 开始复习、重做相关错题、生成变式题 |
| 找到笔记 | 打开笔记、查看原文、整理成复习内容 |
| 预习建议 | 查看预习内容、播放课程播客、加入今日待办 |
| 作业查询 | 打开作业、继续作答、查看 AI 批改 |
| 资料理解 | 查看原文、生成摘要、生成脑图或播客 |

动作必须跳转到实际内容，不得只显示无结果按钮。

## 5.5 添加资料逻辑

点击「+」打开添加资料浮层，提供：

- 上传文件。
- 添加图片或扫描件。
- 自动同步设置。

### 文件处理流程

```text
用户选择资料
→ 保存原文件
→ 识别文件类型与内容意图
→ 解析文本、版式、音视频或手写内容
→ 建立学科、知识点、任务等关联
→ 向用户展示处理结果
```

### 分类原则

- 长时间结构化阅读对象进入「资料」，如书籍、教材、大体量报告。
- 用户形成或收集的短内容进入「笔记」，如截图、板书、短文档、网页片段、课程录音片段。
- 题目文件本身保留在笔记或资料中；识别出的题目可关联到作业、复习和错题。
- 内容只保存一份，各模块通过关系调用，不复制原文件。

## 5.6 语音逻辑

### 状态机

```text
空闲
→ 请求麦克风权限
→ 录音中
→ 识别中
→ 文本确认/直接提交
→ AI 思考
→ 返回答案
```

### 状态表现

| 状态 | 页面表现 |
|---|---|
| 请求权限 | 显示“正在请求麦克风权限” |
| 录音中 | 显示动态波形、停止按钮和提交按钮 |
| 识别中 | 波形弱化，显示“正在识别” |
| 识别成功 | 转为文字并提交或允许用户修改 |
| 权限拒绝 | 说明开启方式，并提供文字输入入口 |
| 识别失败 | 保留页面，允许重新录音 |

## 6. 产品交互流程

## 6.1 文字搜索流程

```text
点击中间动态文字
→ 打开 AI 搜索页
→ 输入问题
→ 点击发送
→ 显示思考状态
→ 返回对话式答案
→ 用户可点击下一步动作、展开记忆依据或继续追问
```

要求：

- 首页示例文字不应自动成为用户问题。
- 进入搜索页后输入框自动聚焦。
- 用户提交后底部输入框保持同一视觉和位置，支持继续追问。
- 返回后保留本轮对话；关闭搜索页后回到原页面。

## 6.2 语音搜索流程

```text
点击首页麦克风
→ 打开 AI 搜索页
→ 自动请求麦克风权限
→ 进入录音状态
→ 用户停止或提交
→ 语音转文字
→ AI 返回对话式答案
```

要求：不得出现“进入搜索页后还要再点一次麦克风”的二次操作。

## 6.3 添加资料流程

```text
点击首页「+」
→ 打开添加资料浮层
→ 选择上传文件 / 图片扫描 / 自动同步
→ 完成授权或文件选择
→ 展示解析进度
→ 展示保存位置和识别结果
→ 可立即查看或继续提问
```

## 6.4 搜索无结果流程

```text
个人记忆无结果
→ 告知未找到个人记录
→ 判断是否适合联网
→ 用户确认或系统按授权执行联网搜索
→ 将外部结果与个人上下文组合回答
→ 明确标记外部来源
```

禁止把外部内容伪装成用户自己的记忆。

## 7. 页面状态与异常处理

| 场景 | 处理 |
|---|---|
| 无网络 | 继续检索本地个人记忆，隐藏联网动作 |
| 搜索为空 | 输入框保持聚焦，不发送请求 |
| 无个人记忆 | 返回可继续添加资料或联网搜索的说明 |
| 麦克风权限拒绝 | 展示系统设置指引和文字输入按钮 |
| 语音识别超时 | 停止录音，允许重试，不丢失已识别文本 |
| 文件解析失败 | 保留原文件，显示失败原因和重试入口 |
| 重复文件 | 提示已存在，允许打开原内容或继续关联 |
| AI 回答失败 | 保留用户问题，显示重新生成入口 |
| 来源失效 | 回答仍可查看，但来源标记为不可访问 |

## 9. 埋点需求

## 9.1 公共字段

所有事件统一携带：

| 字段 | 类型 | 说明 |
|---|---|---|
| user_id | string | 用户 ID |
| session_id | string | 当前会话 ID |
| event_time | timestamp | 事件时间 |
| app_version | string | 客户端版本 |
| page_name | string | 当前页面 |
| entry_point | string | 固定为 sidebar_unified_entry 或后续实际入口 |
| subject_id | string/null | 当前学科 |
| network_status | string | online/offline |
| device_type | string | pad/desktop/mobile |

## 9.2 核心事件

| 事件名 | 触发时机 | 关键参数 |
|---|---|---|
| memo_entry_exposure | 统一入口进入可视区域 | prompt_text、prompt_index |
| memo_prompt_rotate | 示例问题完成一次切换 | from_prompt、to_prompt、interval_ms |
| memo_entry_search_click | 点击中间搜索区域 | displayed_prompt、page_name |
| memo_entry_add_click | 点击「+」 | page_name |
| memo_entry_voice_click | 点击麦克风 | page_name、permission_status |
| memo_search_page_view | 搜索页展示完成 | open_method=text/voice |
| memo_query_input | 用户开始输入 | input_type、query_length，不上报原文 |
| memo_query_submit | 用户提交问题 | query_id、input_type、intent、query_length |
| memo_query_answer_success | 答案展示完成 | query_id、latency_ms、evidence_count、action_count、used_web |
| memo_query_answer_fail | 回答失败 | query_id、error_code、stage |
| memo_evidence_expand | 展开记忆依据 | query_id、evidence_count |
| memo_evidence_click | 点击某条依据 | query_id、evidence_type、object_id、origin |
| memo_action_click | 点击下一步动作 | query_id、action_type、target_id |
| memo_followup_submit | 在答案后继续追问 | parent_query_id、input_type、query_length |
| memo_search_close | 退出搜索页 | duration_ms、query_count、has_action_click |

## 9.3 语音事件

| 事件名 | 触发时机 | 关键参数 |
|---|---|---|
| memo_voice_permission_request | 发起麦克风授权 | previous_permission_status |
| memo_voice_permission_result | 用户完成授权选择 | result=granted/denied/timeout |
| memo_voice_record_start | 开始录音 | start_source=sidebar/search_page |
| memo_voice_record_stop | 停止录音 | duration_ms、stop_method |
| memo_voice_recognize_success | 转写成功 | duration_ms、text_length |
| memo_voice_recognize_fail | 转写失败 | error_code、duration_ms |
| memo_voice_query_submit | 语音内容提交 | query_id、text_length、edited_before_submit |

禁止在分析平台直接上传录音内容和完整转写文本。


### 语音漏斗

```text

```

## 10. 验收标准

### 10.1 首页入口

- 「+」、动态问题、麦克风三个点击区域互不冲突。
- 示例问题每 3 秒切换，具有淡入淡出效果。
- 示例切换不造成入口宽度或布局抖动。
- 中间区域点击后进入搜索页。
- 「+」点击后打开添加资料浮层。
- 麦克风点击后进入搜索页并自动开始语音流程。

### 10.2 搜索结果

- 返回结果采用对话布局。
- 展示直接答案和可执行的下一步动作。
- 记忆依据默认收起。
- 依据可跳转到对应原始内容。
- 底部输入框可以继续追问，样式和首次搜索一致。

### 10.3 异常状态

- 拒绝麦克风权限后可以继续使用文字输入。
- 无个人记忆时不生成虚假个人判断。
- 离线时个人记忆搜索仍可工作。
- 解析失败不删除已上传原文件。

## 11. V1 范围

### 本期实现

- 统一入口展示。
- 示例问题轮播。
- 添加资料入口。
- 文字搜索入口。
- 语音入口及状态变化。
- 对话式结果展示。
- 下一步动作展示。
- 记忆依据收起与展开。
- 核心埋点。

### 本期不实现

- 多轮复杂 Agent 自动执行。
- 未经授权的自动联网。
- 后台自动替用户提交作业或修改原文件。
- 跨用户共享记忆。
- 语音内容长期保存。
